# Проверка NEO FIT 3.0

Дата проверки: 16 сентября 2026. Это отчёт о выполненных проверках, не сертификат безопасности и не подтверждение интернет-публикации.

## Выполнено

**41 автоматический тест — пройдены**, Node.js 22.16.0, встроенный `node:test`:

- валидность двух исходных программ и пустого профиля;
- сохранение пяти подходов из PDF, разделение примерных и фактических весов;
- упражнения по сторонам, ввод десятичных килограммов, добавление упражнения на сегодня;
- независимость программы от черновика/истории, защита от двойного завершения;
- замены по движению и оборудованию, запрет затирания уже введённых результатов;
- ротация и недельное расписание, реальные календарные даты и часовой пояс;
- статусы приёма, два слота в день, исправления и версии планов без переписывания прошлого;
- расчёт питания, различие процентов и ккал, ограничения некорректных параметров;
- импорт без дубликатов, перенос явно указанного пресса из заметки, безопасная обработка строк;
- AES-GCM/PBKDF2, неверный пароль, разделение локальных профилей, смена пароля;
- конфликт двух вкладок, свежая версия при повторном входе, сбой квоты хранилища, откат неудачной смены пароля;
- облачный адаптер с **имитацией HTTP**: пользовательский JWT, зашифрованная очередь, отсутствие токенов в кэше, сетевой сбой и CAS-конфликт;
- запрет публичной сборки с service_role/secret key; обязательная конфигурация для облачного выпуска;
- отсутствие личной истории и HTML-экспорта в публичной оболочке.

`npm run check` — синтаксис JS-модулей и JSON, отсутствие старой функции HTML-сохранения и встроенных пользовательских данных. `npm run build` — успешная сборка статических файлов и Service Worker. Сборка с `--production` без облачных параметров намеренно отклоняется.

## Проверка интерфейса

В Chromium выполнен **DOM-интеграционный тест** с настоящими шаблонами/обработчиками приложения и синтетическим хранилищем:

- главная на 1440 px;
- все 8 вкладок на 390 и 320 px;
- активная тренировка на 390 и 320 px;
- ввод веса/повторов/галочки запускает автоматическую запись через адаптер;
- добавление пресса в занятие не изменяет исходный шаблон;
- завершение сохраняет занятие один раз;
- расписание из двух времён и фактическое время приёма сохраняются.

Всего **23 проверки интерфейса**, ошибок JavaScript не обнаружено; горизонтального переполнения в проверенных ширинах нет. Скриншоты пустого интерфейса находятся в `docs/previews/`.

Ограничение среды: системная политика Chromium блокировала переходы по HTTP, в том числе на localhost. Поэтому проверялся изолированный DOM-рендер приложения, **не полный end-to-end-вход по реальному URL**. Политика браузера не изменялась. Реальные криптография и локальный адаптер проверены отдельно в Node. HTTP локального сервера дополнительно ответил 200 при запросе через curl; это не заменяет браузерную проверку модульной загрузки/Service Worker.

Дополнительный сценарий можно повторить командой `python tests/render_ui.py`, если установлены Python Playwright и Chromium. Путь к Chromium задаётся через `CHROMIUM_PATH`, результаты пишутся в исключённую из Git папку `test-results/`.

## Перенос личных данных

Отдельный приватный JSON проверен на успешную расшифровку и валидность в новой версии. Его содержимое не включено в исходники, тестовые fixtures или скриншоты публичного проекта. Это локальная проверка переноса, не загрузка данных на сервер.

## Ещё не выполнено

- Создание нового репозитория и публикация в GitHub Pages.
- Создание и настройка отдельного Supabase, применение миграции и развёртывание функции регистрации.
- RLS/pgTAP-тесты на реальном PostgreSQL с Auth.
- Реальный вход двух пользователей и синхронизация телефона/компьютера.
- Проверка регистрации при настройках конкретного Supabase, реального refresh/logout и ошибок провайдера.
- Сквозная загрузка ESM и Service Worker по HTTPS; установка на домашний экран и реальные уведомления календаря.
- Полный аудит безопасности/доступности. Не заявляется полное соответствие WCAG.

При публикации эти проверки обязательны. Наличие подготовленных исходников не означает, что внешние сервисы уже работают.
